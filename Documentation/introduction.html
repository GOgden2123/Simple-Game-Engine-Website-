What is Simple Game Engine?

Simple Game Engine (SimpleGE) is a framework for creating video games with a flexible and robust structure. SimpleGE has been ported to C, Javascript, and Python. While the contents of SimpleGE remain the same across implementations, the underlying game engine is different per language. This documentation is about SimpleGE for Python with Pygame 2.6 as the base engine.

About This Documentation

This documentation is meant to show all the components of SimpleGE, and provide a tutorial on how to use the framework. As prerequisites to reading this documentation, the reader will need to be proficient in Python and Object Oriented Programming concepts, and they will need to be familiar with most of the modules inside Pygame 2.6.
